# 🪨 Камінь, Ножиці, Папір ✂️

Проста консольна гра на Python, у якій гравець змагається з комп'ютером.

## 🎮 Як грати

Запустіть файл `main.py` та введіть:

* `к` — Камінь
* `н` — Ножиці
* `п` — Папір

Після цього комп'ютер випадково вибере свій варіант, а програма визначить переможця.

## 🛠 Використано

* Python
* `random.choice()`
* функції
* умовні конструкції `if / elif / else`
* словники

## 🚀 Запуск

```bash
python main.py
```

## 📌 Приклад

```text
Ваш вибір (к — камінь, н — ножиці, п — папір): к

Ви обрали: Камінь
Комп'ютер обрав: Ножиці
🎉 Перемога!
```
